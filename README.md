# Responsive Internship Board

A responsive web project for finding internships by role, company, and domain.

## Features

- Responsive design
- Internship search
- Domain filtering
- Empty state
- Error state
- Keyboard navigation
- Accessible form labels
- Reusable internship card data

## Technologies Used

- HTML5
- CSS3
- JavaScript
